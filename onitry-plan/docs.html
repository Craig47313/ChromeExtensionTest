Tutorial

Ten minutes to a planner that actually knows your week. Each step ticks itself off once you’ve done it in the planner. You can come back here any time from the ? button.

  1. Open the planner

    Pin Onitry Plan from Chrome’s puzzle-piece menu, then click it or press Alt+Shift+P. It opens in the side panel by default. Want it to take a whole tab instead? See Where it lives.

    Open planner

  2. Put in your class blocks

    Open ⚙ → Block days → Edit class blocks, or click the letter next to the date. Pick a day (A, B, C, D, or No letter for Mondays) and press Add block for each class. Each new block starts right after the last one with the same length, so a whole day usually takes a minute. Use Copy from when two days share most of their classes.

    Call a block Free or Study and you’ll get a nudge with something to do when it starts.

    Edit class blocks

  3. Check today’s letter

    The rotation is counted from one date you know. If the letter next to the date is wrong, open ⚙ → Block days and set Known date to any school day you’re sure about. On break? Add it under Breaks & no-school days in the class blocks menu and the rotation pauses until you’re back.

    Fix it in settings

  4. Brain-dump your work

    Type everything into the Add anything… box, one per line. It reads dates, subjects, tests and time estimates out of plain words. Try it here, it uses your real subjects and block days:

  5. Run a focus block

    Press ▶ on a task (or type what you’re doing under What are you doing right now?) and pick a length. The toolbar badge counts down. While it runs, distracting sites are locked hard.

  6. Meet the gate

    Open YouTube during a focus block. You land on the gate instead. Getting through needs a written reason, a wait, and during focus a typed sentence. Every pass goes in your journal, so you can see the pattern later.

  7. Connect Onitry

    Start Onitry, open its ⚙ Configure, copy the browser planner pairing code, then paste it in ⚙ → Onitry here and press Test connection. Now focus blocks start Onitry on the same task, and if it catches you off task the gate locks. To let the planner start Onitry for you, run python native_host/install.py once in the Monitry folder.

  8. Check in at the end of the day

    At your check-in time you get a notification. Rate the day, tap what got in the way, and name the first thing for tomorrow. It becomes tomorrow’s first task.

  9. Read your first weekly review

    On Sunday evening, open Journal → Weekly review. The numbers are always there; press Write my review with Onitry for a short coaching note on the week.

Start here

What it does

Onitry Plan is a school-day planner that pushes back. It knows what’s due, what class you’re in, and, with Onitry, whether you’re actually working, and it gets in the way of the stuff that isn’t.

Plan in plain words

“econ test fri”, “calc hw due next B 40m”. One task per line, pasted all at once if you like.

Knows your schedule

A/B/C/D rotation, your classes, free blocks and breaks. Homework is laid out after your last class.

Focus blocks

A timer, a countdown badge, and the strictest version of the gate while it runs.

The gate

Distracting sites redirect to a page with your to-do list. Getting through costs a reason, a wait and sometimes a typed sentence.

Nudges

Idle check-ins, free-block suggestions, test-tomorrow reminders, a plan prompt and an end-of-day check-in.

Onitry inside

Starts screen monitoring on your task, shows on/off task live, locks the gate when you drift, and can launch the app.

Journal

Everything you do is timestamped: focus blocks, passes and why, check-ins, notes you type.

Weekly review

Your week in numbers, and a short review written by Onitry using your own API key.

Using it

Planning & quick add

The planner has four parts. On a wide screen they sit side by side; in the side panel they’re tabs.

Today
What you planned for today (or carried over), homework due today or tomorrow, anything overdue, and tests up to two days out. Each open task gets a time slot laid end to end from now, or from the end of your last class, so you can see when you’ll be done. If that runs past your cutoff (the end of work hours) it tells you to cut something. Drag the ⋮⋮ handle to reorder.
Week
A rolling 7 days starting today, so tomorrow is always visible, with each day’s letter. Click a day’s header to add something due that day. Below: everything due in the next three weeks.
Free time
Projects and ideas for when there’s “nothing” to do. The gate and the free-block nudge suggest these when your list is empty. Press + to put one on today’s list.
Journal
See Journal & check-ins.

Click any task’s title to edit it: subject, type (to-do, due, test), due date, estimate, whether it’s on today’s list or the free-time list, or delete it (with undo).

Quick add tips: Enter adds, Shift+Enter starts a new line, and pasting a whole list adds one task per line. Undated tasks go on today’s list. The full grammar is in the cheat sheet.

Using it

Block days

Your school rotates lettered days (A, B, C, D) on some weekdays and has unlettered days on others (Mondays). Onitry Plan works out each date’s letter and shows it next to the date, on the week view, and in the weekly review.

Setting it up

  1. ⚙ → Block days. Pick a Known date and what letter it was, which weekdays get letters, and the letters themselves (default ABCD).
  2. Edit class blocks & breaks opens the class blocks menu. Each day type (each letter, plus No letter) has its own list of blocks with a start, an end and a class name. Class names that match a subject get that subject’s color.
  3. Breaks & no-school days (same menu): pick a from and to date and press Add break. The rotation pauses on those days. If your school counts holidays as part of the rotation, don’t add them.

What it changes

  • Today shows a strip of your classes with the current one highlighted. Click it to edit.
  • Homework time slots start after your last class.
  • Quick add understands due next B, D day, on A-day and next c day.
  • When a Free or Study block starts, you get a nudge with the top thing on your list, and in Smart gate mode the gate goes up if something’s due by tomorrow.

Blocks are matched as free by the words free, study, flex, open, unscheduled or off anywhere in the name, so “Study hall” and “Free (library)” both count.

Using it

Focus blocks

Start one with ▶ on any task, from the What are you doing right now? card, from the gate page, or from a nudge. Lengths are 15–90 minutes; the default comes from settings, or the task’s estimate.

  • The toolbar badge shows minutes left (green), minutes over (orange, +5), or ! when Onitry says you’re off task (red).
  • When time’s up you get a notification with ✓ Done and +10 min.
  • Done ticks the task off. Stop ends the block without ticking it.
  • Every block is saved as a session: what, how long, how it ended, and Onitry’s on-task % if it was watching.
  • Starting a new block while one is running ends the old one first.

Using it

Using it

Journal & check-ins

The journal is a timestamped log of your day. You add to it by typing in the box (Enter logs it with the time), and the planner adds to it automatically:

  • ▶ focus blocks started and stopped (with Onitry’s on-task % at the end)
  • ✓ tasks finished
  • 🔓 every gate pass, with the site, length and your reason
  • 🔔 Onitry catching you off task
  • 🌙 end-of-day check-ins

Above it: today’s focus time, tasks done, Onitry’s on-task %, and gate passes. Below it: the last 7 days, collapsed. Your check-in streak counts consecutive days with a check-in.

The end-of-day check-in appears two hours before your check-in time: rate the day, pick what got in the way (YouTube, phone, tired…), and write the first thing for tomorrow. That line is parsed like quick add and becomes a task on tomorrow’s list.

Using it

Weekly review

Journal → Weekly review shows the week (Monday to Sunday) in numbers: tasks done, focus time and blocks, Onitry’s on-task %, gate passes, your average mood, tasks done and missed per subject, which sites you unlocked most, and what you missed.

On Sunday it reviews the week ending today; on Monday it shows the week that just ended; the rest of the week it shows the week so far.

Write my review with Onitry sends those numbers to the Onitry app, which asks Claude for a short review: one line on how it went, what worked, what slipped, and three concrete things for next week tied to your upcoming deadlines. It’s saved, so it’s still there next time. What gets sent.

Using it

Onitry

Onitry is the desktop app that looks at your screen every few seconds and decides whether you’re on task. The planner and Onitry talk over a local connection on your computer:

  • Starting a focus block starts Onitry on the same task, with context it can use: the subject, when it’s due, and what else is on today’s list.
  • The chip in the header shows Onitry’s state: On task, Off task, Onitry watching, idle, not running, or Pair Onitry. The focus card shows what Onitry thinks you’re doing.
  • Ending the block stops Onitry (optional) and records its on-task %.
  • Off task during a block locks the gate. See escalation.
  • Launch Onitry (⚙ → Onitry) starts the app if it isn’t running, and a focus block does it automatically if you leave that option on.
  • If you start monitoring from the Onitry window instead, the planner notes it in your journal.

Pairing

  1. Run Onitry (python gui.py or the menu bar app).
  2. Onitry → ⚙ Configure → copy the browser planner pairing code, like K7QM-29XD.
  3. Here: ⚙ → Onitry → tick Connect, paste the code, press Test connection.

Where it lives

⚙ → Where it lives picks what the toolbar button does:

Side panel
The default. The planner sits next to whatever you’re doing. The ↗ button in its header opens it in a tab.
Its own pinned tab
The toolbar button jumps to the planner tab, or opens it pinned at the far left if it isn’t open.

How it works

Architecture

Onitry Plan is a Manifest V3 Chrome extension with no server of its own. Everything lives in your browser profile, except the Onitry app, which runs on your own computer.

Pages
today.html is the planner, the same page in the side panel (?view=panel), a tab, or a new tab. guard.html is the gate; the URL you were trying to reach rides along after the #. docs.html is this guide. All of them re-render when storage changes, so every open copy stays in sync.
Shared library
lib/planner.js holds the data model, dates, the quick-add parser, block rotation, the gate decision and weekly stats. It has no Chrome dependencies apart from the storage helpers, so the same file runs in the pages, the service worker and Node unit tests.
Service worker
background.js loads lib/planner.js, lib/onitry.js and planner-bg.js. It owns everything that has to keep happening with no page open: focus timers, gate rules, nudges, Onitry polling, escalation, the launcher and the review request. Pages send it commands like {type: 'plan:focus', action: 'start'}.
Why storage is the hub
Chrome can stop the service worker whenever it’s idle, so nothing important lives in its memory. On wake-up it reads storage, recreates its alarms and re-syncs the gate.

How it works

The quick-add parser

parseQuick() turns one line into {title, course, kind, due, plan, estimate, someday}. It runs in passes, each one removing what it understood so the rest becomes the title:

  1. Free-time prefix. A leading ~, someday: or later: puts it on the free-time list.
  2. Letter days (only when block days are on). next B, next b day, B day, on B-day. A bare letter only counts after “next” or as a capital before “day”, so “a day” and “work on a project” are left alone. The date is the next date with that letter, after today.
  3. Estimates. 40m, 40 min, 1h, 1.5h, 1h30.
  4. Dates, word by word: today/tonight, tmrw/tomorrow, weekday names (the next one; said on that day it means today), next fri (next week’s), 10/16, oct 16, 16 oct, in 3 days. A “due”, “on”, “by”, “for” or “before” right in front of a date is dropped. Month/day dates more than two months in the past roll to next year.
  5. Subject. A #tag wins; otherwise the first word that matches a subject name or alias (⚙ → Subjects). The word stays in the title.
  6. Type. Words like test, quiz, exam, summative, midterm, final, assessment make it a test; anything with a date is due; the rest are to-dos.
  7. Today. No date and not free-time? It goes on today’s list.

How it works

Block rotation math

You give one anchor: a date and its letter. To find any other date’s letter, blockLetter():

  1. Returns nothing if the date isn’t a lettered weekday or is a break day.
  2. Walks day by day from the anchor to the date, counting only lettered weekdays that aren’t break days (backwards if the date is earlier).
  3. Moves that many letters along from the anchor letter, wrapping around: letters[(anchor + n) mod 4].

If the anchor itself isn’t a lettered day, it names the next lettered day. Because break days aren’t counted, the rotation picks up after a break exactly where it left off. The walk is capped at about three years either side of the anchor.

dayInfo() then picks the day’s blocks: the letter’s list, or the No letter list for school days without a letter, or nothing on weekends and breaks. blockAt() finds the current and next block by time.

How it works

Gate rules

The decision and the enforcement are separate.

Deciding. guardState(settings, focus, tasks, now, escalatedUntil) is a pure function, checked in this order:

  1. Focus block running and Onitry escalation active → up, strict, reason onitry.
  2. Mode is Off → down.
  3. Focus block running → up, strict.
  4. Mode is Focus → down. Mode is Always → up.
  5. Smart: something due by tomorrow or planned for today, and you’re in work hours → up. Same but in a Free/Study block → up. Otherwise down.

Enforcing. syncGuard() runs whenever tasks, focus, settings, passes or escalation change, and every minute. When the gate is up it writes one declarativeNetRequest redirect rule per gated site without a live pass:

regexFilter:  ^https?://([^/]*\.)?youtube\.com([:/?#].*)?$
resourceTypes: main_frame
redirect:     chrome-extension://…/guard.html#\0

Chrome applies these rules itself before the page loads, so it works even while the service worker sleeps. It’s one rule per site because a single combined pattern hits Chrome’s regex memory limit. Rules use IDs from 1001 up. Only top-level page loads are redirected, so embedded videos on other sites still play.

When a site becomes gated, tabs already open on it are sent to the gate too. A pass is stored as {site: expiresAt}; an alarm fires when the next one expires to re-gate it.

How it works

The Onitry bridge

Onitry runs a tiny HTTP server (core/bridge.py) bound to 127.0.0.1 on port 47323. The extension calls it with fetch; every call has a short timeout and never throws, so a closed Onitry just shows as “not running”.

CallBodyReturns
GET /v1/ping—Is Onitry there? Is the code right? (No code needed.)
GET /v1/status—running, on/off task, task, activity, on- and off-task seconds, interrupts, paused
POST /v1/task{task, details}Starts monitoring that task (stopping any other)
POST /v1/stop{}Stops monitoring
POST /v1/review{stats}The weekly review text

Why a web page can’t abuse it

  • It only listens on 127.0.0.1, so other machines can’t reach it.
  • Everything but ping needs the pairing code in an X-Onitry-Token header. A custom header forces the browser to ask permission first (a CORS preflight), and Onitry only says yes to chrome-extension:// origins.
  • Any request from a normal website’s origin is refused outright, and the Host header must be 127.0.0.1 or localhost, which stops DNS-rebinding tricks.
  • The code is compared in constant time and lives in Onitry’s data/bridge_token. Delete that file to make a new code.

On the Onitry side, bridge requests are handed to the GUI thread through its queue, so a browser click behaves exactly like pressing Start in the Onitry window.

How it works

Off-task escalation

During a focus block the service worker polls Onitry every 30 seconds. The first time Onitry reports off_task (and the option is on):

  1. escalatedUntil is set to 10 minutes from now in pl:meta.
  2. All gate passes are revoked.
  3. The gate re-syncs as if every site were newly gated, so open distracting tabs are sent to the gate.
  4. A notification and a journal line record it.

While escalated, guardState keeps the gate up even in Off mode, the gate page says “Onitry saw that.” and hides the pass form, and the service worker refuses pass requests. Each further off-task report pushes the 10 minutes out again. Ending the focus block clears it.

How it works

Launching Onitry

Extensions can’t start programs, but they can talk to a native messaging host: a small program registered with Chrome that only listed extensions may call.

  1. native_host/install.py writes a launcher script that runs native_host/host.py with your Python, and registers it as com.onitry.host for Chrome, Chromium, Brave, Edge and Arc. It only allows this extension’s ID, which is fixed by the key in the manifest (dadagbofodnllhcohbhmjkdolklihcgn).
  2. When a focus block starts and Onitry isn’t reachable, the extension sends {cmd: "launch"}. Chrome starts the host, which checks whether the bridge port is already open and, if not, starts gui.py detached from Chrome (so closing Chrome doesn’t close Onitry), logging to data/native_launch.log.
  3. The extension pings the bridge once a second for up to 20 seconds, then starts the task.

The block starts right away; the focus card shows “Connecting to Onitry…” until this finishes.

How it works

Review pipeline

  1. weekStats() builds the week from your local data: totals, done and missed per subject, which sites you unlocked and your reasons, missed tasks, each day’s letter, focus time, mood, derailers and up to 8 journal lines, plus next week’s deadlines.
  2. The service worker posts it to Onitry’s /v1/review (up to 2 minutes).
  3. Onitry (ai/review.py) sends it to Claude with a short coaching prompt, using its own API key. The model is claude-opus-5-5 unless ONITRY_REVIEW_MODEL says otherwise. If the model declines, Anthropic’s server-side fallback retries on another model.
  4. The text comes back and is saved in pl:reviews under the week’s Monday.

This needs Onitry’s dev or BYOK edition (your own API key). The managed edition doesn’t do reviews yet; the numbers still show either way.

How it works

Privacy

  • All planner data stays in chrome.storage.local in your Chrome profile. There’s no account and no server.
  • The only network calls go to 127.0.0.1 (Onitry on your own computer).
  • The one thing that leaves your computer is the weekly review, and only when you press the button: Onitry sends that week’s stats, including task titles, gate-pass reasons and journal lines, to the Claude API.
  • Onitry itself sends screenshots to Claude while it’s monitoring; that’s Onitry’s own behavior, configured in Onitry.

Troubleshooting

The letter is wrong
Set ⚙ → Block days → Known date to a school day you’re sure of. Check which weekdays get letters, and that breaks are added (or not, if your school keeps counting through them).
A site isn’t gated
Is the gate up? Check the hint under the focus card, or Gate rules → Right now. Sites you added need Chrome’s permission; re-save settings to be asked again. Errors show on chrome://extensions → Onitry Plan → Errors.
“Onitry not running”
Start Onitry, or press ⚙ → Onitry → Launch Onitry. Only one Onitry window can own the bridge port.
“Pairing code not accepted”
Copy the code again from Onitry → ⚙ Configure. It changes only if data/bridge_token is deleted.
“Launcher not installed”
Run python native_host/install.py in the Monitry folder, then fully quit and reopen Chrome. If you moved the Monitry folder or changed Python, run it again.
Review says it needs an API key
Reviews use Onitry’s own key: set it in Onitry (dev or BYOK edition).
No notifications
macOS: System Settings → Notifications → Google Chrome → allow. Also check Focus / Do Not Disturb.
New tabs don’t open the planner
“Every new tab” needs the tabs permission. Pick it again in ⚙ and accept Chrome’s prompt.

FAQ

Can I just turn the gate off?
Yes, ⚙ → Distraction gate → Off. The one exception is Onitry escalation during a focus block, which you can turn off under ⚙ → Onitry.
Does it work without Onitry?
Everything except live on/off-task status, escalation, launching and the written review. The review numbers still show.
Is it the same as Inkwell?
No. Inkwell is the notes and drawing extension. They’re separate and share nothing.
Can I back up my data?
It lives in Chrome’s storage for this extension. Removing the extension deletes it; reloading it in developer mode doesn’t.
What about my phone?
Not yet. Desktop Chrome only.
